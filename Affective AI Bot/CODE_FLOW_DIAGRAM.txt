ALGORITHM DETAILS (For Technical Questions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PITCH EXTRACTION (voice_tone.py Line 158)
   Method: YIN algorithm (librosa.yin)
   - Autocorrelation-based
   - Robust to noise
   - Returns F0 (fundamental frequency)

2. ENERGY CALCULATION (voice_tone.py Line 175)
   Method: Root Mean Square (RMS)
   Formula: sqrt(mean(audio²))
   - Measures loudness
   - Range: 0-1

3. SPEECH RATE (voice_tone.py Line 212)
   Method: Syllable counting
   - Detect vowel transitions
   - Count per second
   - Typical: 2-6 syllables/sec

4. MFCC FEATURES (voice_tone.py Line 186)
   Method: Mel-frequency cepstral coefficients
   - 13 coefficients
   - Captures voice quality
   - Used in all speech systems

5. FUSION ALGORITHM (fusion.py Line 89)
   Method: Weighted averaging
   Formula: final = α × text + (1-α) × tone
   - α = text_weight (configurable)
   - Can be dynamic based on confidence
   - Smoothed over last 3 predictions
